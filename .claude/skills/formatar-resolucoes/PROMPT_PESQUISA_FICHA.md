## O que fazer, para cada questão do seu arquivo `pesq_in_K.json`
1. Descubra o fato que decide o item.
2. Procure primeiro na APOSTILA no Drive (ferramentas Google Drive, carregue-as com ToolSearch: "select:mcp__Google_Drive__read_file_content"): "Apostila - v2 - Conhecimentos DF e RIDE (Parte 1)" id 1VzYkFkTKQLnY2GoPM5V4SPgbqGMnMQg1 e "(Parte 2)" id 1-Ua5D_cwoQYqWBouwahiyKy5bWcZjFJ9 (leia-as uma vez e procure por todos os itens do seu arquivo). A ficha atual pode ter omitido algo que a apostila traz.
3. Se a apostila não traz, pesquise na web (WebSearch/WebFetch, carregue com ToolSearch "select:WebSearch,WebFetch") em fonte CONFIÁVEL, nesta ordem: órgãos oficiais (GDF, Agência Brasília, Codeplan, IPEDF, CAESB, Adasa, Semana/SEMA-DF, IBGE, Câmara/Senado, IPHAN, UNESCO, Novacap, Terracap, Secretarias), universidades/artigos acadêmicos, enciclopédias (Wikipedia só como apoio, nunca única). Registre a URL exata e a passagem literal que sustenta cada fato.
4. NUNCA invente dado, número, data ou nome. Se não achar fonte confiável, marque "inconclusivo". Dados que mudam a cada edição (população, ranking, índices) levam o ANO/EDIÇÃO e a fonte na própria linha.
5. Diga se o fato CONFIRMA, CONTRARIA ou é INCONCLUSIVO em relação ao gabarito do arquivo (você NÃO muda gabarito; só informa).
